## Generer le temoin

La generation du temoin transforme les entrees du circuit en valeurs intermediaires verifiables. Dans snarkjs, cette etape precede la preuve et depend du fichier WASM ou de l artefact equivalent. Le chapitre decrit les controles de format, le lien avec le circuit et les erreurs de donnees attendues. Aucune execution nest lancee dans ce parcours.
